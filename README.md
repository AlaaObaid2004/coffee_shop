# ☕ Coffee Shop Landing Page

A single-page landing website for a coffee shop, built with HTML5 and CSS3. The page presents the shop's brand, menu, customer reviews, and a table reservation form.


[Coffee Shop Preview](images/preview.png)

## Features

- Fixed navigation bar with smooth in-page links
- Hero section with a call-to-action button
- About section introducing the shop
- Menu section showcasing 8 drinks with images, descriptions, and prices
- Customer testimonials section
- Table reservation form (name, email, persons, date, time, message)
- Embedded Google Map for the shop location
- Footer with contact info, quick links, and social media links
- Font Awesome icons

## Built With

- HTML5
- CSS3
- Font Awesome
